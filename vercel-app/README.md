# Tic Tac Toe Game

A simple Tic Tac Toe game built with React that uses custom images for X and O.

## Features

- 3x3 game board
- Custom images for X and O markers
- Win detection for horizontal, vertical, and diagonal lines
- Draw detection
- Game status display
- Restart game functionality
- Responsive design

## Deployment

This project is ready to be deployed on Vercel.

### Steps to deploy to Vercel:

1. Push this code to a Git repository (GitHub, GitLab, or Bitbucket)
2. Log in to your Vercel account
3. Click "New Project" 
4. Import your repository
5. Keep the default settings and click "Deploy"

## Customizing Images

To use your own images for X and O, update the following constants in `src/App.js`:

```javascript
const PLAYER_X_IMAGE = "URL_TO_YOUR_X_IMAGE";
const PLAYER_O_IMAGE = "URL_TO_YOUR_O_IMAGE";
```

Replace the URLs with direct links to your images of Walid Regragui and Abdellatif Wahbi.

## Available Scripts

### `npm start` or `yarn start`

### `npm run build` or `yarn build`

Builds the app for production to the `build` folder.
